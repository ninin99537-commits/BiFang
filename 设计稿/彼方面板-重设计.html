      锚点＝消息级位置。插在「任务之前」的规则会被后面的内置段覆盖；想要更强的约束就插在「任务之后」或「最后」。
      
      
      
        发送顺序：五个锚点落在哪
        
      ① 最前          你的段
② system        身份句 + 全部更新规则（内置，含生理段：开关开时才有）
③ 主提示词之后  你的段
④ system        【最新用户输入·仅供场景判断】（有玩家输入时才有）
⑤ 任务之前      你的段
⑥ user          任务正文 ← 最长的内置段（正文 / 世界书 / 状态卡 / 台账 / 生理说明 / 恋爱说明 / 仅更新已追踪）
⑦ 任务之后      你的段（以前破限的位置）
⑧ 最后          你的段
（末条若是 assistant 且预填充关着，会自动补一句收尾 user）
