## 二、跑之前：这轮改了什么（一句话版）

| 改了什么 | 你能看到的效果 |
|---|---|
| **提示词 A1–A6** | NPC 的"典型一天"更具体；长时间没更新后，状态会体现"这段时间过去了"；`当前目标` 不再只有"达成/放弃" |
| **字段合并** | `心里惦记` + `秘密想法` → **`心事`**；`隐藏目标` → **`藏起来的打算`**（面板人物页会看到新名字） |
| **新增两个字段** | **`衣物/随身物`**、**`伤势/体力`**（人物页编辑态可见；有值后主 AI 会看到，防穿帮） |
| **隐藏键 `最后剧情时刻`** | 你看不到，它是给"逐 NPC 跨度"用的（本版**只写不读**） |
| **`恋爱动向` 并入 `近期关键事件`** | 关系页那块「最近一轮」不再单独显示，改在关键事件里 |
| **原则 12「世界近况」** | 若世界书里有"世界动向/世界时间/公共事件"，模型会拿它推演生活，但**必须能说出信息来源** |

## 三、跑几轮时看这五处（重点）

### ① 旧卡迁移：内容有没有"消失"（**最重要**）
打开一个**改造前就有档案**的人物（例如艾莉）：
- [ ] 人物页能看到 **`心事`**，且里面的内容**包含**原来"心里惦记"和"秘密想法"写的东西
- [ ] 能看到 **`藏起来的打算`**，内容来自原"隐藏目标"
- [ ] 面板上**不再出现** `心里惦记` / `秘密想法` / `隐藏目标` 三个旧名
- [ ] 如果两处都有值（新旧并存），新值在前、旧值以 `；` 接在后面 —— **两条都没丢**

> 判失败的样子：字段是空的、或者只剩新值一半。那说明迁移没落地，报我。

### ② 跨度：长时间没更新后，状态有没有"过日子"
- 找一个 **1 天以上没更新**的人物（或隔一天再更新）
- [ ] 更新后它的 `当前在做 / 位置 / 当前状态` 能看出"这段时间过去了"（不是原样照抄）
- [ ] 但**不会**凭空编出"三天里发生了五件大事"（长跨度只补痕迹，不补剧情）
- [ ] `近期关键事件` **没有**被塞进"日常流水账"（它仍然只装值得记住的事）

### ③ 新字段：分工有没有混
- [ ] `伤势/体力` 只写身体（伤在哪/程度/影响），不写情绪
- [ ] `当前状态` 只写情绪/精神，**不写伤情**
- [ ] 两者**不重复同一件事**（不会两边都出现"绷带渗血"）
- [ ] 没伤没累时，`伤势/体力` 是**空的**，不是"状态良好"

### ④ 恋爱：门槛生效、关键事件有账
- [ ] 小幅好感变化（比如 +3）**不会**单独占一条 `近期关键事件`
- [ ] 跨阶段 / 名分变化 / 开局 → **会**出现在 `近期关键事件` 里
- [ ] 关系页不再单独显示「最近一轮」那块（已并入）

### ⑤ 世界近况：会不会"凭空知道"
- [ ] 若世界书里有世界动向：NPC 反应合理，且**能说出是怎么知道的**（"听邻居说"、"集会上宣布"）
- [ ] NPC **不会**知道只有玩家视角才有的事（这是防全知铁律，任何一轮都要过）
- [ ] 世界书里**没有**这类内容时，NPC 也不会凭空假设"世界出事了"

## 四、出问题怎么报（三样东西）

1. **哪个人物、哪个字段**（面板上照抄字段名）
2. **更新前后的值**（截图或文字都行）
3. **该轮正文的时间标记**（`剧情时间` 那一行）

有这三样，我能直接定位到是"模型输出"还是"合并/迁移"的问题。

## 五、两条已知局限（不是 bug，别当缺陷报）

1. **世界近况是"条件生效"**：只有烟火**在该聊天真正跑过一轮、写下 `【烟火】世界动向` 条目**时，彼方才会自动读到。当前聊天（`最后生还者_2026-08-04`）实测**没有该条目** → 这层暂时等于没有。想试：先让烟火跑一轮。
2. **逐 NPC 跨度还没接消费方**：`最后剧情时刻` 现在只写不读，所以你看不到"她三天没更新"这种逐人判断；本版只有**全局跨度**。
