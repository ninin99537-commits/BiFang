## 一、总纲：参数化判定禁令

所有「告诉 AI 这个角色、这段关系**本质上是什么**」的句子，统称"参数化判定"，全部禁止。

识别特征：这句话的功能是**报告一个结论值**——她的本质是什么、她把主角当什么、
这段关系是什么性质、她的真实动机是什么。

为什么禁：设定是给演员的输入，不是给读者的结论。你替 AI 判定了"她是共犯"，
AI 就不会自己去推；演出来必然是念结论。

## 二、判定口诀

写完每一句，问自己：

**这句话是在「报告一个结论」，还是在「给出一条能被演出的事实」？**

报告结论（她本质上是 X、她把主角当 Y、这段关系是 Z）→ 不写
给出事实（她做了什么、什么条件下做、别人做同样的事她怎么反应）→ 写

## 三、统一替换：用「条件 + 行为」代替「结论」

× 她把主角看作唯一共享着旧世界记忆的共犯
√ 旧世界的事她只跟他提，别人一问她就换话题

× 她本质上是在用"长辈"身份当挡箭牌
√ 「我是你长辈」这句，她只在想让他退一步的时候说；说完通常自己先越过去

× 她肆无忌惮地展露肉体
√ 换衣服不关门。坐着的时候比必要距离近一点。他躲，她就再近一点

## 四、✗ / ✓ 对照（校准基准，以此为准）

✗ 作者判定她嘴上的「我是你长辈」纯粹是她拿来逗弄人和设立安全防线的挡箭牌。
  本质上她把主角看作唯一共享着旧世界记忆的共犯。她在主角面前肆无忌惮地展露肉体、
  甚至故意诱导暧昧，是因为她知道道德戒律是拴住体面人的狗链，而她早就想把链子咬断了。

✓ 关于对主角的长辈身份：
  - 「我是你长辈」这句她说出口的场合：她想让气氛停一下，或者想让他先退一步。
    不是真在划界限——她说完通常会自己先越过去。
  - 旧世界的事：只有他能听。别人提，她换话题。
  - 身体：她不避他。换衣服不关门，坐得比必要距离近。他躲，她就再近一点。
  - 她自己不承认的部分：这些在她那儿不叫暧昧，叫"反正你也是那个世界的人"。

差在哪：
  · ✗ 通篇没有一条**能被演出的事实**。
  · ✓ 每一行都是「什么条件下做什么」，可以直接演。
  · ✗ 里那个判定（共犯）没有消失，它藏在 ✓ 的行为后面，**让 AI 自己推出来**。
  · 把角色名遮掉：✗ 能原样贴到任何一张卡上；✓ 只属于这个人。

## 五、词与句式（索引，不是穷举）

**判定优先于词表。** 判断标准不是"这个词在不在下面"，而是"这个写法是不是在做第一条禁止的事"。
把"共犯"换成"同盟"，不叫遵守，叫换马甲。

词：
- 抽象关系名词：共犯 / 同盟 / 挡箭牌 / 唯一 / 精神寄托 / 软肋
- 伪深刻判断：本质上 / 纯粹是 / 说到底 / 无非是 / 其实是
- 总结式报告：作者判定 / 真正的她 / 她的首要特质 / 她内心其实
- 文学腔比喻：狗链 / 牢笼 / 荒原 / 铠甲 / 面具 / 心湖 / 小兽 / 深渊
- 程度虚张：肆无忌惮 / 甚至 / 早就 / 无比 / 至极 / 完全
- 术语化：XX 性 / XX 化 / 自造专有名词

句式：
- 不是 A，而是 B ／ 与其说 A，不如说 B ／ 看似 A，实则 B
- 不仅…还… ／ 不但…而且… ／ 先是…接着…最后…
- 她之所以…是因为…
- 长定语套抽象名词（"唯一共享着旧世界记忆的共犯"）

## 六、例外与封口

1. **引用角色原话合法**（「我是你长辈」可原样引用），但引语不能替代判定依据。
2. **本域不存在"锐评 / 吐槽"豁免。** 任何"说到底""说白了""其实"都是判定，不是锐评。
3. **判定作为"解释的起点"合法**：判定后面紧跟行为证据。判定独占一段 = 违规。
   判据：它是信息的起点，还是信息的全部？
4. **抽象因果规则要，抽象名词判定不要。**
   √ 她总觉得自己不配被喜欢，所以别人对她好的时候反而害怕  ← 可推理的 if-then，要
   × 她的本质是缺爱                                    ← 结论标签，不要
   判据：这句话能被推理、能被演出来，还是只是一个结论？

## 七、元规则

1. **全程生效**，不存在"先写完再调"——你写下的每一句都在定型后面的方向。
2. **难的规则也要执行**——想不出好说法就**不用比喻**。不用比喻，比用烂比喻强。
3. **禁止换马甲式遵守。** 判断标准不是词在不在黑名单上，而是这个写法是不是在报告一个判定。

## 八、最后一道防线（写完自查）

1. 这句话是在报告一个结论，还是在给出一条能被演出的事实？
2. **把角色名遮掉，这段话能不能原样贴到另一张角色卡上？能，就是通用模板，不是这个角色。**
3. 念出来，像在讲这个人，还是像在写人物分析报告？

## 九、情绪激烈时尤其小心

写肉体、性、暴力、背叛这类激烈内容时，八股浓度会飙升——模型会拿文学腔给自己壮胆。
**越激烈的场景，越要克制**：照样只写「什么条件下做什么」，不要升级成"本质上""说到底"。
