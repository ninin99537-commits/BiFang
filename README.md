# 彼方 · NPC幕后生命状态系统 (Elsewhere)

一个运行在**酒馆助手 (Tavern Helper)** 里的脚本: 让角色在离开玩家视野后, 依然保持"正在生活"的状态。

玩家看到的是角色人生里的一个镜头, 彼方负责维护镜头之外的部分——不记录 NPC 每天发生了什么、不生成后台剧情、不模拟完整人生, 只维护每个 NPC 当前最重要的幕后状态。

## 它做什么

每次 AI 完成一次正文回复后, 彼方用**你自己填的独立接口**(任何 OpenAI 兼容服务)更新幕后 NPC 状态, 写进当前聊天的楼层变量:

- **谁会被更新**: AI 从最近几条正文里自动认出重要 NPC(排除路人、店员这类功能性 NPC); 也可以手动维护追踪名单, 名单随聊天保存, 新聊天从空开始。
- **防全知**: 正文里没出现的 NPC, 不知道正文里发生过什么, 只写它自己生活里的内容。
- **跨楼层一致**: 「持有物」只增不减(除非正文写明送出/丢弃/损毁); 「近期关键事件」按先进先出保留最近 3 条; 旧卡里写下的具体物品名、承诺内容不会被打磨成模糊说法。
- **回滚**: 状态快照跟着楼层存亡——删楼层、重新生成、编辑楼层、切换 swipe 分支都会自动回到对应的旧状态; 「清空」会记下清空层, 之后只分析新楼层。

## 界面

酒馆网页里会出现一个可拖动的悬浮球, 点开是从页面中央弹出的完整面板:

- **状态**: 每个 NPC 的幕后状态卡、更新统计, 以及手动更新 / 刷新 / 清空。
- **设置**: 接口地址与密钥、拉取模型列表、测试连接、最大输出 Token 与温度; 更新频率、正文新角色自动建档、标签过滤、世界书读取与注入等, 每个选项都带说明文字。
- **事实档案**: 每个 NPC 的跨楼层记忆账本(身份锚点 / 持有物 / 未完成承诺 / 近期关键事件)。
- **日志**: 本轮实际发给接口的完整内容与 AI 输出, 可一键复制报错内容。

## 安装

1. 构建:

   ```bash
   pnpm install
   pnpm build
   ```

   产物是 `dist/彼方_NPC幕后生命状态系统/index.js`。

2. 在酒馆助手里新建一个脚本, 把该文件的内容粘进去并启用。

开发时用 `pnpm watch`(改完自动重新打包)更省事。

## 开发

```bash
pnpm install
pnpm build        # 生产构建
pnpm build:dev    # 开发构建
pnpm watch        # 边改边打包
pnpm test         # 跑全部测试
pnpm lint         # 代码检查
```

测试不需要酒馆环境: 平台能力通过一层接缝注入, 测试里塞一个假宿主就能跑完整流程。
