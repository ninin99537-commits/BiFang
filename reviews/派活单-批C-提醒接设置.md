## 1. 缺口的完整面（**两处**，不是一处）

盘点报告只写了高阈值。批 C 派活前实跑发现低阈值是**完全对称**的同一个病。

| 位置 | 行为 | 判定 |
|---|---|---|
| `引擎规则.ts:466` | `高阈 = 阈值?.高 ?? 连续高阈值默认` | 接 settings |
| `引擎规则.ts:467` | `低阈 = 阈值?.低 ?? 连续低阈值默认` | 接 settings |
| `update.ts:385` | 传 `{ 高: 连续高阈值, 低: 连续低阈值 }` | 传了 |
| `提醒.ts:808` | `if (连高 >= 连续高阈值默认)` | **写死常量** |
| `提醒.ts:812` | `if (连低 >= 3)` | **写字面量 3**，连常量都没用 |

### 实跑证据（`tmp/probe-连续低阈值-对照.ts`）

连续低张力 = 4，幕纲「冲突」（避开批 A 的留白豁免）：

```
用户设置 连续低阈值 = 3：  引擎调整 1 行（改成阴影）   提醒「低张力」1 条   ← 一致
用户设置 连续低阈值 = 6：  引擎调整 0 行（尊重设置）   提醒「低张力」1 条   ← 只有引擎生效
```

### 为什么一直没发现

`:812` 的字面量 `3` **恰好等于** `连续低阈值默认`（`schema.ts:58`）。
所有用例都用默认值 → 「默认值下行为正确」恒真 → 缺口被默认值盖住。
只有**改过设置的用户**才看得到。

这是「无人看守区」的典型：不是没人测，是**测试不构造那个输入就永远看不到**。

## 2. 改法

### 2.1 签名加可选参数（三层贯通）

```ts
// 提醒.ts:29
export interface 提醒上下文 {
  当前幕: number;
  /** 张力阈值: 生产路径由 settings 传入; 不传 → 退回 schema 默认常量（老用例零变化） */
  阈值?: { 高?: number; 低?: number };
}

// 提醒.ts:546
export function 结构提醒(账本: 导演账本, 当前幕: number, 阈值?: { 高?: number; 低?: number }): string[] {
  const 上下文: 提醒上下文 = { 当前幕, 阈值 };
  ...
}

// 提醒.ts:505（提醒规则表里那一条）
{ 名: '节奏', 生成: (账本, { 当前幕, 阈值 }) => 节奏提醒(账本, 当前幕, 阈值) },

// 提醒.ts:792
export function 节奏提醒(账本: 导演账本, 当前幕?: number, 阈值?: { 高?: number; 低?: number }): string[] {
  const 高阈 = Number.isFinite(Number(阈值?.高)) ? Number(阈值.高) : 连续高阈值默认;
  const 低阈 = Number.isFinite(Number(阈值?.低)) ? Number(阈值.低) : 连续低阈值默认;
  ...
  if (连高 >= 高阈) { ... }
  if (连低 >= 低阈) { ... }
}
```

⚠️ **兜底写法照抄 `引擎规则.ts:466-467`**，不要另写一套：

```ts
const 高阈 = Number.isFinite(Number(阈值?.高)) ? Number(阈值?.高) : 连续高阈值默认;
```

理由：两处判据必须同源。引擎用 `Number.isFinite(Number(x))` 而不是 `x ?? 默认`，
是因为 `settings` 解析失败时可能传进 `NaN` —— `NaN ?? 默认` 会保留 `NaN`，
然后 `连高 >= NaN` 恒为 false，**提醒永远不响**（静默失效，比写死更难查）。

### 2.2 调用点

```ts
// 取料.ts:245
结构提醒: 设置.导演.平静模式
  ? []
  : 结构提醒(账本, (Number(账本.已分析轮数) || 0) + 1, {
      高: 设置.导演.连续高阈值,
      低: 设置.导演.连续低阈值,
    }),
```

### 2.3 不传 → 老用例零变化

`阈值` 是可选参数，不传时退回 `连续高阈值默认` / `连续低阈值默认`。
`提醒.ts:812` 原本的字面量 `3` 换成 `连续低阈值默认` 也是 3 —— **行为等价**，不是行为改动。

## 3. 判据 ⑪a / ⑪b

**必须拆两条。** 只写一条的话「只实现了一条腿」照样绿（与 ④a/④b 同理）。

### ⑪a（高阈值）

```
夹具：张力.最近节拍 = ['受挫','反转','受挫']（连续 3 场高张力），幕纲**非**「生活」
调用：结构提醒(账本, 11, { 高: 6 })
断言：「停在高点」提醒 **不出现**
对照：结构提醒(账本, 11) 或 { 高: 3 } → **出现 1 条**
```

### ⑪b（低阈值）

```
夹具：张力.连续低张力 = 4，幕纲**非**「生活」（否则撞批 A 的留白豁免）
调用：结构提醒(账本, 11, { 低: 6 })
断言：「低张力」提醒 **不出现**
对照：结构提醒(账本, 11) 或 { 低: 3 } → **出现 1 条**
```

### ⚠️ 对照组是必须的（防假绿）

只写「传 6 → 不出现」是**假绿**：
- 如果函数根本不读参数 → 「不出现」也可能成立
- 如果夹具压根没触发这条规则 → 同样「不出现」

所以每组必须有「**不传 → 出现 1 条**」的对照，证明夹具本身能触发。

这与批 A 里 ⑤ 那条教训同型（留白账逾期 7 > 阈值 5，本来就该催，专门验了不是假绿）。

### 变异

| 变异 | 操作 | 必须红 |
|---|---|---|
| M⑪a | `节奏提醒` 里 `连高 >= 高阈` 改回 `连高 >= 连续高阈值默认` | 只 ⑪a |
| M⑪b | `节奏提醒` 里 `连低 >= 低阈` 改回 `连低 >= 3` | 只 ⑪b |

**归因必须互不越界**：M⑪a 只让 ⑪a 红、⑪b 绿；M⑪b 反之。
若两条一起红 → 夹具共享了「阈值」这个使机制恒真的条件，重写夹具。

## 4. 不许做的事

1. **不许只接高阈值** —— 那就是修一半，低阈值照旧。
2. **不许改 `提醒.ts:812` 的阈值语义** —— `>=` 不变、`3` 换成常量不变行为。
3. **不许动 `节奏提醒` 里其它数字**（`连低 >= 3` 之外还有 `近六.length >= 4`、
   `总幕 >= 3` 这些，它们**不是**可配阈值，不在本批范围）。
4. **不许跑 `prettier --write` 整个文件** —— `提醒.ts` 有历史遗留格式差异，
   会把批 C 变成格式大爆炸。只改要改的行。
5. **不许在批 C 里顺手改别的东西**（单一定义纪律）。
