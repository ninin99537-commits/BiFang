# 缺陷 · P1-8 强制拆壳绕过 onUnmounted（P1-7 因此白修）

> 需求方（opencode）2026-11-13，真机复核时发现。已发 `#71`。

## 一、结论

`壳去重.ts` 的 `清掉同id壳()` 用 `元素?.remove?.()` 拆旧壳。
**`remove()` 不会触发 Vue 的 `onUnmounted`。**

后果：旧壳里由 `onUnmounted` 负责清理的东西**全部泄漏** ——
`resize` 监听（P1-7 刚修的）、`量球定时器`、`量球观察器`、`坞观察器`、`removePanelShadow()`。

## 二、实测证据（jsdom + Vue 3）

```
★ 直接 remove DOM 后 onUnmounted 被调用: false | 记录 = []
★ 显式 app.unmount() 后 onUnmounted 被调用: true
```

```ts
const app = createApp({ setup() { onUnmounted(() => 记录.push('跑了')); return () => h('span','x'); } });
app.mount(子);
宿主.remove();          // ← P1-8 干的事
// 记录 = []            ← onUnmounted 没跑
```

## 三、为什么这是真缺陷（不是理论问题）

1. **监听挂在父窗口上**。`面板机制.ts:627` 是 `挂了resize的窗口?.addEventListener('resize', ...)`，
   窗口是**酒馆页面**，不是 iframe 内部。iframe 被移除，监听照样活着。
2. **真机已经有重复壳**。最后生还者聊天里有 2 个同 id 壳：
   - 序号 0：位置 `0,0`、`pointerEvents: none`、`body 子元素 0`、无 `.dj-root` → **僵尸壳**（app 从没 mount 成功）
   - 序号 5：位置 `468,93.4`、`pointerEvents: auto`、有 `.dj-root` → 正常壳
3. **僵尸壳拆了没副作用**（它没有 app），但**正常旧壳拆了就是泄漏**。
   如果重复加载过 N 次，父窗口上可能叠了 N 份监听。

## 四、根因

`清掉同id壳(doc, id)` 只能拿到 DOM 元素，拿不到那个 Vue app 实例。
这是接口设计的硬伤 —— 调用方（`悬浮球界面.ts`）手里有 `app`，但它没传下去。

## 五、三个修法

### A. 让调用方传卸载函数（推荐）

```ts
// 壳去重.ts
export function 清掉同id壳(doc: Document, id: string, 卸载?: (el: any) => void): number {
  const 旧壳 = ...;
  for (const 元素 of 旧壳) {
    卸载?.(元素);        // 先 app.unmount()
    元素?.remove?.();
  }
  ...
}

// 悬浮球界面.ts
const 已挂载的app = new WeakMap<HTMLIFrameElement, App>();
已挂载的app.set($app[0], app);
清掉同id壳(document, String(useHost().vars.scriptId()), el => 已挂载的app.get(el)?.unmount());
```

**优点**：依赖显式可见，调用方能看见"拆壳要卸载"。
**缺点**：`WeakMap` 只能记本进程创建的壳，记不住上一个进程遗留的（但那种也没有 app 实例了，无所谓）。

### B. 全局注册表

```ts
(window as any).__dj壳 = (window as any).__dj壳 || new Map<string, App>();
```

`清掉同id壳` 自己去查。跨 iframe 也能用（顶层 window 是同一个）。

### C. 不拆，改成复用

**不推荐**。`壳去重.ts` 自己的注释写了「复用等于两套 app 抢同一个 document」。

## 六、处置建议

**并进 P1-8，不单独立批。** 理由：这是同一个 bug 的两面，分开修会留下
"看起来修好了"的中间态（用例绿、真机还漏）。

## 七、验收标准

改完之后必须能做到：

1. 构造一个已挂载的壳 → 调 `清掉同id壳` → 断言 `onUnmounted` 跑过（用一个计数器）；
2. 变异测试：把 `卸载?.(元素)` 那行删掉，用例必须变红；
3. 真机验证：重载插件后，`document.querySelectorAll('iframe[script_id]')` 里同 id 只剩 1 个，
   且父窗口上 `resize` 监听数量不增加（可在 `酒馆调试.mjs` 里数 `getEventListeners`，或加一个调试计数）。
