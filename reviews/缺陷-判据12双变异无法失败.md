剧情导演 · 判据 ⑫ 双变异无法失败（2026-11-13，需求方复核 dsh 批 A）

# 结论

`tests/daoyan-留白判据.test.ts` 的 `[3]` 组（判据 ⑫）**两条变异都绿**。
判据形同虚设 —— 它能通过，但不能失败。

# 复现

```
M⑫-1  躲债节拍去掉 '日常'（:752）        → 53 通过 / 0 失败
M⑫-2  兜底加 `&& 节拍 !== '日常'`（:778） → 53 通过 / 0 失败
```

两条都**没有红**。（脚本：`tmp/mut-12.py`）

# 根因：夹具让主路径和兜底路径同时命中，互相掩盖

`[3]` 的夹具：

```ts
const 收束账 = 账本({ 章回: { 进度: '收束', 收束起始场: 1, 幕纲: 幕纲('生活'), 当前幕号: 1 } });
造(收束账, '日常')
```

`已分析轮数 = 10`、`收束起始场 = 1` → `收束已用 = 10 ≥ 收束预算场(8)` → **预算用尽**。

于是 `:751-784` 的 `if (收束中)` 块里，**两段都会执行**：

| 行 | 条件 | 动作 |
|---|---|---|
| `:753` | `躲债节拍.includes('日常')` = true | `节拍 = 换成`（无候选 → `'高潮'`） |
| `:773` | `收束已用(10) >= 预算(8)` = true | `:778` `if (节拍 !== '兑现伏笔' && 节拍 !== '高潮')` → 此时已是「高潮」，**跳过** |

## 为什么 M⑫-1 不红

去掉 `躲债节拍` 里的 `'日常'` 后：

- `:753` 不成立 → 节拍**仍是「日常」**
- 但 `:773` 预算用尽 → `:778` 兜底把「日常」改成「高潮」
- **结果还是「高潮」**，断言 `节拍 ∈ {高潮, 兑现伏笔}` 照样通过

**主路径被删，兜底替它兜住了 —— 断言看不到差别。**

## 为什么 M⑫-2 不红

`:752` 主路径先跑，把「日常」改成「高潮」；到 `:778` 时 `节拍 === '高潮'`，
那个新加的 `&& 节拍 !== '日常'` 条件**永远用不上**。

**兜底被改，主路径替它兜住了 —— 断言同样看不到差别。**

# 这违反报告 `:686-691` 的要求

> 收束期把日常改掉有**两条路**，`:775` 只是兜底：
> - `:749` `躲债节拍 = ['日常','小胜']` → `:751` 换成 `兑现伏笔` 或 `高潮` —— **主路径**
> - `:775` `if (节拍 !== '兑现伏笔' && 节拍 !== '高潮') 节拍 = '高潮'` —— **兜底**，只管收束预算用尽那一刻
>
> 只测 `:775` 的话，「给 `:749` 加豁免」这种回退**会漏**。两条各一次变异，才算钉住这个语义。

现在的情况比「只测兜底」更糟：**两条都测不到**，因为夹具同时触发了它们，
任何一条被删，另一条都能补上。

# 修法：两条变异必须各配一个**只命中自己**的夹具

## ⑫a —— 主路径（预算未用尽）

```ts
// 收束 + 导演要日常 + 预算未用尽 → 只有 :752 主路径能改
const 主路账 = 账本({ 章回: { 进度: '收束', 收束起始场: 1, 幕纲: 幕纲('生活'), 当前幕号: 1 } });
// ⚠️ 已分析轮数 必须是 10 这种「收束已用 < 8」的值
// 即 当前幕 - 收束起始 + 1 < 8 → 当前幕 < 8
// 账本() 默认 已分析轮数 = 10，所以要么改 已分析轮数，要么改 收束起始场
```

推荐：`已分析轮数: 5, 收束起始场: 1` → `收束已用 = 5 < 8`，预算**未**用尽。
此时只有 `:752` 主路径会改节拍，`:778` 兜底不执行。

**M⑫-1 必须让 ⑫a 红。**

## ⑫b —— 兜底（预算用尽）

```ts
const 兜底账 = 账本({ 已分析轮数: 10, 章回: { 进度: '收束', 收束起始场: 1, ... } });
// 收束已用 = 10 >= 8 → 预算用尽
```

但**光这样不够** —— 主路径 `:752` 会先把「日常」改成「高潮」，兜底就看不到「日常」了。

要让兜底单独暴露，必须让**主路径不命中**：

```ts
// 导演要的节拍不在 躲债节拍 里（比如 '受挫'），但兜底会把它改成 '高潮'
造(兜底账, '受挫')
// :752 躲债节拍=['日常','小胜'] 不含 '受挫' → 主路径跳过
// :773 预算用尽 → :778 把 '受挫' 改成 '高潮'
```

**M⑫-2 必须让 ⑫b 红。**

# 验收口径

```
M⑫-1（删 :752 的 '日常'）      → 只有 ⑫a 红
M⑫-2（:778 加 !== '日常' 豁免） → 只有 ⑫b 红
```

⚠️ 另外：`[4]` 属性穷举的「收束」列同样预算用尽（`已分析轮数 = 10`），
所以它覆盖的也是「主路径 + 兜底」的组合，无法归因。
穷举本身不要求归因，但**⑫ 的两个独立组必须自己构造夹具**，不能复用穷举那份。
