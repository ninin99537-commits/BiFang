## 2. 转正的技术约束（别绕过）

1. **不许手抄断言**。`verify-step4-behavior` / `verify-step4-layer1` / `verify-step5-mut` / `verify-seam-watch` 都是**从 `.vue` 现场抽取**（括号配平 / ASCII 锚点），
   转正后必须仍然从源码抽。**复制进 `tests/` 会变成「测自己抄的那份」** —— 本批实测过两次：抄的那份和 `.vue` 脱钩，源码改了它照样绿。
2. **不许 `import` 任何 `.vue`**。`tests/build.mjs` 没有 `.vue` loader（交接单 §7.1）。转正后只能「读文本 → 抽取 → 求值」。
3. **剥注释只剥整行注释**（`^\s*(//|/\*|\*|<!--)`）。`设置界面.vue` 有 `accept="image/*"`，块注释正则会从那里起吃掉 122 行真代码（§7.8）。
   **行尾 `//` 也要剥**（`[^:]` 排除 `https://`）：否则「真调用删掉 + 行尾留一句 `// TODO 本该调 函数X(`」能把「调用数 ≥1」骗成绿（实测 37/0 全绿）。
4. **变异必须保留**。没有变异，「实现退化成空函数」这套断言照样绿。变异可以用「改字符串再求值」，不必真改源码。
5. **锚点失配不许抛错**：抛错 = 崩溃式红，后人看到堆栈而不是「哪条判据不成立」。改成记一笔、由跑全量变成一条普通 FAIL；
   且判据要写成**阻断式** `!锚点丢了 && 判据(红)` —— 只加一条红不够，后续判据看到「A09 红了」照样 PASS（实测 7/4 而不是 5/6）。

## 5. 怎么跑这两份装置（`tsx` 跑不了）

```powershell
node tests/build.mjs reports/verify-p0-2.ts tmp/_rp.mjs && node tmp/_rp.mjs            # 17/0
node tests/build.mjs reports/verify-seam-watch.ts tmp/_rs.mjs && node tmp/_rs.mjs      # 8/0
```

⚠️ **别用 `npx tsx`**：`package.json` 没有 `type: module`，tsx 走 cjs，两份脚本里各有 top-level await → 直接报错。
`tests/build.mjs` 是 esbuild 的 JS API 封装，参数里有 `format: 'esm'`，所以能跑。

**「hash 能证明内容没坏，证明不了怎么用」** —— 收到存档件的人拿到 hash 一致、跑不起来，第一反应会是「拷坏了」。
所以存档件必须自带跑法，这条是硬要求。
